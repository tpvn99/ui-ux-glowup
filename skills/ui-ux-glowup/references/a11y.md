# Accessibility — WCAG 2.2 AA

Two layers. `audit.mjs` covers what can be read from the page (contrast, alt, labels, accessible names, focus ring, tap targets, zoom, reduced motion). `a11y.mjs` covers behaviour:

```bash
node <skill-dir>/scripts/a11y.mjs <page|url> [--json a11y.json]
```

Read-only. It presses Tab up to 60 times, checks ARIA and landmarks, then reloads at 320 px. Each finding has a fix; exit 1 on errors.

## Custom widgets are operated for you

`a11y.mjs` reloads the page and uses the keyboard alone on up to 3 tab lists, 5 disclosure buttons (`aria-expanded` + `aria-controls`), 3 dialog triggers and 3 menu buttons. It reports what does not respond. Comboboxes (3), listboxes (3) and trees (2) are tried with the arrow keys, and draggable items must have a button alternative. Date pickers, data grids, menu bars and custom sliders are not driven: write a scenario for those.

## Modals and menus: write a scenario

For anything the script cannot open on its own (a dialog behind a login, a multi-step flow), write a scenario. For each dialog, drawer and menu add a scenario (`testing.md`): open it, `{ "expect": { "focusWithin": "[role=dialog]" } }`, `Tab` and `Shift+Tab` stay inside, `Escape` closes, and `{ "expect": { "focusOutside": "[role=dialog]" } }` after closing returns focus to the trigger.

## By hand — what no script proves

- **Screen reader pass** (VoiceOver, NVDA, TalkBack, JAWS) on the primary journey: names, order, announced errors and status messages (4.1.3). No script here drives a real screen reader; the checks above only verify what a screen reader would be given (names, roles, states, focus).
- **Text spacing** (WCAG 1.4.12) and browser zoom on a real device: nothing clipped or overlapping. Zoom 200 % and 400 % are simulated at 640 and 320 CSS px.
- **Pointer alternatives**: anything dragged also works with clicks (2.5.7).
- **Consistent help** (3.2.6): contact or help link in the same place on every page.

A clean report means these checks found nothing, not that the page is conformant. Say what was not tested.
